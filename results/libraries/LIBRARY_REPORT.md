## 7. Caveats

- 'Quantified in the compendium' uses all compendium conditions (incl. TEST) to define the candidate site set of predicted libraries; this is site existence only (r2_data N10). Methods must additionally restrict to sites measured in the scored condition / DEV cache (`load_library(..., sites=...)`).
- iPTMnet licence: its readme states both CC BY-NC-SA 4.0 (download terms) and CC BY 4.0; we apply the more restrictive CC BY-NC-SA 4.0 (compatible with our non-commercial use; same terms as PSP). Derived libraries are not committed.
