## Proposed changes
1. **§1 runtime targets are 50–250× too loose; tighten and define measurement. (must)** Measured z is 0.2 ms/cond and 0.09 s/compendium. Set targets: single-sample ≤5 ms/cond end-to-end (key mapping included), compendium ≤10 s excluding one-off library build; report library-build time separately. Protocol in §5 "Runtime": `OMP/MKL/OPENBLAS_NUM_THREADS=1` and =16 runs, warm cache, median of 5 repeats, wall-clock split into (load/mapping, scoring, null/calibration); a `bench_runtime.py` fixture in the harness timing every baseline on the same 200 fixed DEV conditions. Without this, "fastest" is unverifiable.
2. **§7B: replace the ad-hoc list with one Bayesian linear-Gaussian core model. (must)** x_s = Σ_k W_sk a_k + b_c + ε_s, ε_s ~ N(0, σ_c² v_s) (v_s = site noise variance estimated on non-TEST compendium, unsupervised), prior a ~ N(0, τ² K) with K a kinase–kinase covariance (item 3). Posterior mean and posterior z = μ/sd in closed form (one p×p solve, p≤~400 → ~5–10 ms; Woodbury when n_sites<p). This unifies "weighted z", "shrinkage for small n", "mlm deconvolution" and "family borrowing", gives a principled uncertainty for kinases with 0–4 substrates (53+89 of 321 GT kinases), and handles multi-target Hijazi drugs jointly. Hyperparameters: τ, family-coupling ρ, library mixing α only (≤5 scalars). Keep plain z/ulm as the reference.
3. **Add explicit kinase–kinase priors (K) as an experiment node. (should)** Candidates, each tested separately: Manning group/family tree kernel; Kinase Library PSSM similarity (leakage-safe); substrate-overlap Jaccard on PSP. Evidence: LITERATURE §5.6; 53 GT kinases have no quantified PSP substrate and can only be scored via predicted edges or K. Risk: family borrowing raises *non-inhibited* paralogs (Hijazi negatives) → add to §5 a diagnostic "M1 restricted to same-family negatives" so gains in coverage are not paid for by within-family discrimination.
4. **Constrain learned components to kinase-agnostic, low-dimensional parametrisations (§7C). (must)** Per-edge "responsiveness" weights learned from training inhibitors memorise drug→site responses with ~10² independent drug groups and median 8 conds/kinase; they cannot help T-unseen kinases. Instead: edge weight w_sk = f(features; θ) with θ ≤ ~20 shared across kinases (in vivo/in vitro flag, PSP LT/HTP refs, predicted-score percentile per library, KL motif percentile, site compendium variance, n sites on same protein). No per-kinase or per-edge free parameters in the primary method. Rule in §7: any learned parameter count >50 needs a T-unseen non-inferiority check on DEV (leave-kinase-out folds) before adoption.
5. **Add learning-to-rank stacking as the ensembling mechanism (§7E). (should)** Objective = M1 directly: pairwise logistic loss within condition (GT target vs negatives), features per (c,k) = standardised scores from 3–6 base models/libraries + log(m_eff) + library-coverage indicators + self-site signal (inhibitor contexts flagged). Linear or monotone GBM with ≤30 params, kinase-agnostic, fit in grouped CV, sample weights 1/(#pairs of that kinase) to match kinase-macro M1. Cheap at inference (one dot product).
6. **Matrix factorisation across compendium (new §7F). (could)** (a) Nuisance removal: learn a low-rank basis V (r≈5–20) of global responses (stress, cell cycle, normalisation drift) on non-TEST compendium; in single-sample mode project input on V and add V as nuisance covariates in model 2 (cost: one r-dim solve). (b) PLIER-style prior-constrained factorisation for substrate expansion. Leakage: factors fit on drug conditions encode drug→site responses; fit only on conditions with **no GT label** (≈926 of 1,937) plus the current training fold, never on held-out fold/TEST groups. Same restriction should apply to "data-driven substrate expansion" in §7C.
7. **Calibration must not depend on permutations (§5, §7B). (must)** 1,000-perm null = 200 s/compendium (breaks item 1). Use analytic null with effective m (m_eff from mean substrate–substrate correlation on non-TEST compendium; collapse multi-sites per protein) and/or a per-condition empirical null (median/MAD of all kinase scores, Efron). Evidence: 0.177 vs 0.05 at m≥20 in near-null conditions above.
8. **Model-selection hygiene in §7/§8. (must)** Adoption rule "improves M1" needs a threshold and multiplicity control: adopt only if paired grouped-bootstrap 90% CI of ΔM1 >0 on DEV CV; log the number of configurations tried per branch; final choice re-evaluated on repeated grouped CV over all SEEDS (re-split folds with seeds 1–4) to estimate winner's-curse optimism before FREEZE.
9. **§7A: specify how predicted-KS scores enter the sparse W. (should)** Full R2/R3/Cantley matrices are 503×350k dense; use per-kinase top-k restricted to measured sites with weight = calibrated percentile^γ, k and γ tuned on DEV (≤2 params/library). Store W as CSR (expect ≤~2×10⁵ edges → runtime unchanged).
10. **§10 compute: no change needed** — everything proposed is CPU sparse/dense linear algebra; GPUs unnecessary except optional GBM stacking.
